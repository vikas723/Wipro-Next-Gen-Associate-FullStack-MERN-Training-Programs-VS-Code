In my ToDo Manager App Project the frontend part is named as client
Backend part is named as Server

Execution steps: 

Step 1: I have deleted node modules files for both client and server so do npm install epress and install create-react-app to get the node modules and then name the app to Client for the create-react-app. 

Step 2: Start the Client

Step 3: Then open a new Terminal and then start the Server

Step 4: Client will run on port 3000 http://localhost:3000

Step 5 : Server will run on port http://localhost:5000/todos

Step 6 : All the executions will be updated in the todos,json file in server in a json format 

Step 7 : The user can enter the task and they can also edit and delete the task


User Story 1: 

In user stoy 1 i have implemented React Components and Hooks (useState, useEffect) in ToDoPage also it is the main page for my app and called it in App.js file

User Story 2:

In this story i have implement the express js and the RESTful API methods like add, delete, update in the todoRoutes.js file and called it in server.js file using express and cors

User Story 3:

In this story i have handled the error handling using try and fetch in todoform and todo list and also i have implemented button as a reusable components
