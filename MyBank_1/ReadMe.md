Steps to execute MyFin Bank Project :

Backend:

1) Unzip the project and open in vscode terminal
2) Install node modules for backend using npm install and also install npm init-y for package.json file
3) Go to command prompt and go to MyBank_1 -> Backend folder
4) I have used mysql database so start the mysql server and apache in xampp
5) go to http://localhost/phpmyadmin site create database named myfin_bank and there click my_fin database
6) In ny_fin database I have created tables for my project 
7) Start running the backend in command prompt using node Server.js
8) Backend will run in server port 5000
9) In commmand prompt of backend folder all the details will be fetched
10) In phpmyadmin also backend results will be fetched



Frontend: 

1) Install node modules for frontend using npm install
2) Go to command prompt and go to MyBank_1 -> Frontend folder
3) Start running the frontend in command prompt using npm start
4) Frontend will run in the localhost 3000
5) First register for Customer 
6) Login as Customer 
7) Then register as admin
8) And login as admin
9) Then we can perform Deposit withdrawal 
10) Ensure all the ports are running correctly

In VS Code terminal also we can run just by installing node modules for both frontend and backend and start mysql server and apache in xampp and also open http://localhost/phpmyadmin -> my_finbank database
