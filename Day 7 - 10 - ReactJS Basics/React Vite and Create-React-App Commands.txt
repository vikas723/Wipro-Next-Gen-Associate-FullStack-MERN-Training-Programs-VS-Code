Install Tailwind CSS:

npm install tailwindcss @tailwindcss/vite

Configure it in the vite.config.js - by adding tailwindcss() in plugin

import tailwindcss from '@tailwindcss/vite' //import it in vite.config.js

@import "tailwind.css"; to globally import the tailwind css in index.css
